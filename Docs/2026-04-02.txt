 逐条回答，先把所有设计疑问澄清，再统一更新文档。

  ---
  Q1：冰墙为什么需要HP打破？

  你的质疑是对的。回头看《光与朽》的核心哲学——"无惩罚宽容机制"，强迫玩家主动打冰墙其实是增加负担，和游戏调性不符。

  重新给两个选项：

  ┌───────────┬──────────────────────┬──────────────────────────────────────────┐
  │           │         机制         │                 适合场景                 │
  ├───────────┼──────────────────────┼──────────────────────────────────────────┤
  │ A（推荐） │ 纯30秒自动消失，无HP │ 宽松体验，冰墙只是阶段性阻挡             │
  ├───────────┼──────────────────────┼──────────────────────────────────────────┤
  │ B         │ HP=2,000 + 30秒兜底  │ 有策略深度，玩家可以主动打墙恢复激光路线 │
  └───────────┴──────────────────────┴──────────────────────────────────────────┘

  我倾向A：冰墙是 Boss 施压的视觉元素，让激光"暂时受阻"产生紧张感，但不应该要求玩家专门去处理它。30秒后自动消失，玩家专注打 Boss 即可。

  ---
  Q2：为什么180°扫射 / 激光可以从中心发射吗 / BOSS本体是否旋转360°？

  三个问题合在一起回答，因为是同一个技能的不同维度。

  我之前的180°扫射设计是错的，用户质疑是对的。问题的本质是：扫射逻辑复杂，但玩家反制手段又不直觉，整个设计不好成立。

  重新提案——技能2改为：BOSS固定射线，直接指向光棱塔

  ┌────────────┬───────────────────────────────────────────────────────┐
  │    要素    │                         设计                          │
  ├────────────┼───────────────────────────────────────────────────────┤
  │ 激光方向   │ 从 Boss 中心出发，固定朝向光棱塔，不扫射              │
  ├────────────┼───────────────────────────────────────────────────────┤
  │ BOSS本体   │ 不旋转，body 正常朝向不变，只有 LineRenderer 射线延伸 │
  ├────────────┼───────────────────────────────────────────────────────┤
  │ 持续时间   │ 3秒                                                   │
  ├────────────┼───────────────────────────────────────────────────────┤
  │ 命中护盾   │ 护盾扣血，不冻结光棱塔                                │
  ├────────────┼───────────────────────────────────────────────────────┤
  │ 命中塔本体 │ 冻结光棱塔1.5秒（护盾已破时）                         │
  └────────────┴───────────────────────────────────────────────────────┘

  这样设计的优点：
  - 不需要扫射逻辑，Boss 不旋转，实现简单
  - 玩家护盾 = 天然抵挡机制，逻辑自洽
  - 护盾扣血有意义——护盾平时扛普通怪，Boss 技能2会加速消耗护盾

  ---
  Q3+Q4：玩家激光命中BOSS让BOSS偏移 → 怎么躲激光？逻辑对不上？

  你说得对，这个机制是错的，我之前没想清楚。

  来解释为什么对不上：玩家的激光永远从塔打向
  Boss（方向固定），"推力偏转扫射角"理论上可行，但实际操作里玩家感知不到"我在推激光方向"，体验很差。

  所以直接取消"推力偏转扫射角"这个机制，技能2改为上面说的固定射线+护盾机制。玩家的反制是维持护盾 HP，而不是"推激光"。

  ---
  Q5：护盾被激光照到，是否冻结光棱塔？

  护盾存在时，激光命中护盾 → 不冻结，护盾扣血。护盾破了才能命中塔本体 → 触发冻结。

  这在实现上也很简单：激光 Raycast 检测命中目标，判断是 Shield 碰撞体还是 Tower 碰撞体，分别处理即可。

  ---
  Q6：光棱塔被冰冻后，是否显示冰冻图片？玩家连点可提前解冻？

  两个答案都是肯定的：

  1. 显示冰冻图片：光棱塔上叠加一层半透明蓝白冰封图，持续1.5秒后渐隐消失
  2. 连点解冻：这是非常好的移动端设计（QTE 感），玩家连续点击屏幕可以加速解冻进度，增加参与感，避免"干等挨打"的挫败感
