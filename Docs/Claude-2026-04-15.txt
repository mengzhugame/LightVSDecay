 实现方案

 步骤一：新建 HapticFeedback.cs（单例工具类）

 文件：Assets/Scripts/Core/HapticFeedback.cs

 - 枚举 HapticType { Light=100, Medium=200, Heavy=400, Critical=800 }（值 = 毫秒）
 - Singleton 模式（DontDestroyOnLoad）
 - 平台分支：
   - UNITY_ANDROID && !UNITY_EDITOR：通过 AndroidJavaObject 调 vibrator.vibrate(long ms) 实现精确时长
   - UNITY_IOS && !UNITY_EDITOR：Handheld.Vibrate()（iOS 忽略时长，震一次，满足基本需求）
   - Editor：只打 Log，不震动
 - 节流机制：Dictionary<string, float> _lastTriggerTime，默认间隔 0.5s，支持自定义 key

 步骤二：新建 BattleHapticController.cs（事件订阅集中器）

 文件：Assets/Scripts/Core/BattleHapticController.cs（挂到 GameManager 同节点）

 集中订阅 GameEvents，避免污染现有类：
 OnEnable  → 订阅事件
 OnDisable → 取消订阅

 GameEvents.OnPlayerHealthDamaged → HapticFeedback Heavy（无节流，每次体力受伤都震）
 GameEvents.OnPlayerShieldDamaged → HapticFeedback Light（节流 key="shield_hit"，0.5s）
 GameEvents.OnShieldBroken        → HapticFeedback Heavy + CameraShake(0.4, 0.35)
 GameEvents.OnBossFrictionStart   → HapticFeedback Medium + CameraShake(0.25, 0.4)
 GameEvents.OnBossDeath           → HapticFeedback Critical

 步骤三：BOSS 入场处加 Haptic

 文件：Assets/Scripts/Logic/Boss/BaseBossController.cs

 在 SpawnRoutine 已有的 CameraShake.Instance?.Shake(...) 旁加：
 HapticFeedback.Instance?.Trigger(HapticType.Heavy);

 步骤四：BOSS 阶段切换处加 CameraShake + Haptic

 分别修改三个 Boss Controller 的 phase trigger：
 - VolcanoBossController.cs — Phase 2 / Phase 3 触发处各加 CameraShake(0.55, 0.5) + HapticFeedback Heavy
 - GlacialBossController.cs — Phase 2 触发 + AbsoluteZero 激活时各加
 - DarkBossController.cs — 确认是否有阶段切换代码；如有 IsEnraged 触发点则同上

 步骤五：大招激活处加 Haptic

 修改 OverloadManager.cs 的 Activate 方法，激活后加 HapticFeedback.Instance?.Trigger(HapticType.Medium)
