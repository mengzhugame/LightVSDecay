**1. 大招增加宽度为什么会“爆亮”？当前改的是 LineRenderer 还是 shader 的 BeamWidth？**

当前游戏运行时改的是 **`LineRenderer` 的宽度**，不是 shadergraph 的 `_BeamWidth`。

链路是：

[OverloadManager.cs](D:/Project/LightVSDecay/Assets/Scripts/Logic/Player/OverloadManager.cs:50) 里大招宽度倍率默认是 `widthMultiplier = 2f`。

我也搜了代码里 `_BeamWidth` / `BeamWidth` 的运行时设置，没有发现 `material.SetFloat("_BeamWidth", ...)` 之类调用。所以技能和大招都不是在运行时改 shader 参数 `_BeamWidth`。

爆亮的原因大概率是：你的激光材质是 HDR/透明/发光类效果，材质默认颜色也有 HDR 强度，例如 Prefab 里 `defaultLaserColor: {r: 0, g: 3, b: 3, a: 1}`。当 LineRenderer 宽度变粗时，屏幕上发光像素面积变大，但每个像素亮度没有降低，Bloom 后处理会把更大面积的高亮一起扩散，于是看起来像“爆亮”。这不是 `_BeamWidth` 被改导致的，而是“发光材质 + 线宽变粗 + Bloom”的常见结果。

另外我发现一个小问题：副激光宽度在大招时会被大招倍率乘两次。

[LaserController.cs](D:/Project/LightVSDecay/Assets/Scripts/Logic/Player/LaserController.cs:186)

```csharp
public float CurrentSubLaserWidth => CurrentLaserWidth * SUB_LASER_WIDTH_RATIO * overloadWidthMultiplier;
```

因为 `CurrentLaserWidth` 已经包含 `overloadWidthMultiplier`，这里副激光会变成 `base * skill * ratio * overload^2`。如果大招倍率是 2，副激光就是 4 倍宽度影响，这也可能加重爆亮，尤其 Prism/副激光存在时。

**建议修改方案，等你确认后我再动手**

我建议分三步修：

1. **修副激光大招宽度重复乘的问题**
   
   把：

   ```csharp
   public float CurrentSubLaserWidth => CurrentLaserWidth * SUB_LASER_WIDTH_RATIO * overloadWidthMultiplier;
   ```

   改成：

   ```csharp
   public float CurrentSubLaserWidth => CurrentLaserWidth * SUB_LASER_WIDTH_RATIO;
   ```

   这样副激光不会在大招时异常变宽、变亮。

2. **做“宽度变粗但不爆亮”的亮度补偿**
   
   在 `LaserBeam` 里保留 `laserWidth` 作为真实宽度，同时根据 `laserWidth / baseWidth` 自动降低 `_BaseColor` 的 HDR 强度，比如：

   ```csharp
   brightnessScale = 1f / Mathf.Sqrt(widthRatio);
   ```

   或者更保守一点：

   ```csharp
   brightnessScale = Mathf.Lerp(1f, 0.6f, Mathf.InverseLerp(1f, 3f, widthRatio));
   ```

   这样激光变宽时，单像素亮度会略降，总体不会被 Bloom 炸开，但视觉上仍然更粗。这个方案不需要改 shadergraph，风险比动 shadergraph 小。

3. **增强广域透镜的视觉与实际收益**
   
   有两个可选方向：

   方案 A，直接调数值：把 `Passive_Wide.asset` 从 `1.2/1.4/1.6/1.8/2.0` 提到例如 `1.3/1.6/1.9/2.2/2.5`。这样 Lv5 从 `0.5 -> 1.25`，玩家会明显感觉更粗，碰撞体积也同步更大。

   方案 B，分离“视觉宽度”和“伤害判定宽度”：例如伤害判定仍按 `2.0x`，视觉显示按 `2.5x` 或 `2.8x`，让玩家更容易看出来，但不会把实际命中范围放得过大。这个更可控，但代码改动稍多。

我的推荐是：**先做 1 + 2 + 方案 A**。也就是修掉副激光重复乘、给宽激光做亮度补偿、把广域透镜数值轻微加强。这样改动最小，玩法逻辑清晰，玩家也能真正感到“宽了且更容易命中”。确认后我再开始修改。
