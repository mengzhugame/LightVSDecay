也就是说现在 `ad.Show()` 没传失败回调。微信激励视频常见流程正是你贴的示例：`show()` 失败后要 `load()` 再 `show()`。当前代码既没有接 `Show` 的 failed 回调，也没有 `Load` 重试，所以一旦首次 show 失败，SDK 的 promise 失败被吃掉，Unity 侧 `onFail` 也不会执行，于是表现就是：点击按钮后没弹广告、没报错、按钮可能还被 UI 禁用了。
