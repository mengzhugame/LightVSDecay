  touch，而模拟器的鼠标操作不产生 touch 事件，两边都漏了。

  修复逻辑：去掉预编译分支，两种检测同时运行：
  - 鼠标检测：覆盖编辑器 / PC / 安卓模拟器
  - 触摸检测：覆盖真机

  现在编辑器里按住左键横向拖动鼠标即可触发引导完成。

为什么大招充能满了，没有调用新手引导的手指预制体？

找到根本原因了。看 ChangeState() 第 584 行的执行顺序：

  OnEnterReady()
    → ShowReadyBubble()  ← 第 333 行：设置 hasSeenOverloadTutorial = true 并 Save()
  GameEvents.TriggerOverloadStateChanged(Ready)  ← 事件之后才发出
    → BattleTutorialDirector.OnOverloadStateChanged()
        → 检查 _shouldShowOverloadTutorial

  两个叠加问题：

  1. 你之前开发测试时已经触发过大招，ShowReadyBubble() 早就把 hasSeenOverloadTutorial = true 存入了
  PlayerPrefs。BattleTutorialDirector.Start() 读到的就是 true，所以 _shouldShowOverloadTutorial =
  false，引导永远不显示。
  2. 即使从头开始，ShowReadyBubble() 和 BattleTutorialDirector 共用同一个 flag，但 Bubble 优先写，下次启动就失效了。

现在运行游戏，遮罩挖洞的位置显示是正确了，但是鼠标点击洞内的按钮没有任何反应。这是什么问题？

问题出在点击穿透的实现机制上。

  根本原因：Unity UI 的点击事件流程是先由 GraphicRaycaster
  做射线检测决定谁"接收"事件，IPointerClickHandler.OnPointerClick() 是在射线已命中之后才调用的回调。当前代码在回调里
  return，只是说"我不处理"，但射线已经被遮罩 Image 吃掉了——下方按钮根本没有机会参与射线检测。

  正确做法：实现 ICanvasRaycastFilter 接口的 IsRaycastLocationValid()。这个接口在射线检测阶段就介入：返回 false
  表示这个点"射线穿透"，GraphicRaycaster 会继续向下检测下层按钮。

using 正常，UnityEngine.EventSystems 包含 ICanvasRaycastFilter。

  ---
  机制对比：

  ┌───────────────────────────────────────────────┬──────────────────────────────┬─────────────────────────────────┐
  │                     方式                      │           介入阶段           │              效果               │
  ├───────────────────────────────────────────────┼──────────────────────────────┼─────────────────────────────────┤
  │ IPointerClickHandler + eventData.Use()        │ 回调阶段（事件已被遮罩吃掉） │ 下层按钮永远收不到事件 ❌       │
  ├───────────────────────────────────────────────┼──────────────────────────────┼─────────────────────────────────┤
  │ ICanvasRaycastFilter.IsRaycastLocationValid() │ 射线检测阶段（最早期）       │ 返回 false → 射线直接穿透到按钮 │
  │                                               │                              │  ✅                             │
  └───────────────────────────────────────────────┴──────────────────────────────┴─────────────────────────────────┘

  现在孔洞内的按钮可以正常响应点击；孔洞外的区域 IsRaycastLocationValid 返回 true，遮罩正常拦截误触。
