逻辑：
1. 淡入 redBodyEffect alpha 0→1（1.5s）

## 技能2：冰封射线（完全重写）

**原实现**：60°/s 旋转扫射
**新实现**：固定方向，从 Boss 中心朝光棱塔射出蓝色激光 3 秒

### 流程
1. 蓄力（`freezeRayChargeUpDuration = 1s`）：Body03 水晶闪烁（`Body03BlinkRoutine`）
2. 计算方向向量（一次性，不每帧重算）
3. 启用 LineRenderer（position[0]=Boss中心, position[1]=命中点）
4. 每帧 Raycast（检测 Shield + Tower 层）：
   - 命中 **Shield 层**：持续扣护盾血（500/s，可配置），不冻结
   - 命中 **Tower 层**：触发冻结 1.5s（单次，`freezeRayHitThisCast` 守卫）
   - 未命中：射线延伸至最大长度
5. EndVFX 节点跟随射线末端位置
6. 3s 结束，关闭 LineRenderer 和 EndVFX

**Inspector 新增字段**：
- `laserLineRenderer`：Laser 节点的 LineRenderer
- `laserEndVFX`：EndVFX 节点的 Transform
- `body03Crystal`：Body03 节点的 SpriteRenderer
- `freezeRayChargeUpDuration`（默认 1s）
- `freezeRayShieldDamagePerSecond`（默认 500）

**删除**：`freezeRayRotationSpeed`、`freezeRayVisual`（旧旋转扫射用）

## 技能4：绝对零度（完全重写）

**新实现**：BingCi 动画 + 冰刺投射体 + 条件惩罚

### 流程
1. **拔出（0.4s）**：BingCi01~04 各自向外侧位移 0.4 单位（Lerp）
2. **旋转对准（0.6s）**：各冰刺旋转刺尖朝向光棱塔，错开 0.1s 依次开始（Slerp）
3. **射出**：在各 BingCi 世界坐标生成 `IceSpikeProjectile`，隐藏精灵（alpha=0），错开 0.15s
4. **等待结算**（最长 10s）：所有冰刺 destroyed 或 hitTower
5. **惩罚**（任意冰刺命中塔）：塔受当前血量 30% 真实伤害 + 冻结 3s + 召唤 15 只 FrostSlime
6. **再生**（2s 延迟后 0.5s 淡入）：BingCi 复位原始坐标，alpha 0→1

### IceSpikeProjectile（新脚本）
- HP=5000，速度=16 units/s，层级=BossPollutionBall（可被激光检测）
- `TakeDamage(float)` → 血量耗尽时 `OnDestroyedByLaser` 回调
- `OnTriggerEnter2D`（Tag=Tower/Shield）→ `OnReachedTower` 回调
- 超时 10s → 视为命中塔

**Inspector 新增字段**：
- `bingCiTransforms[4]`、`bingCiRenderers[4]`
- `iceSpikeProjectilePrefab`
- 各动画时长参数（`bingCiPullOutDuration` 等）
