# 真机性能问题分析与修复方案
**日期**: 2026-04-16  
**目标机型**: 红米 K80（Android）  
**问题现象**: 始终 30fps，进入第二/三章战斗时瞬间掉到 15fps

---

## 问题一：始终 30fps（主因）

### 根因
Unity 在 Android 平台的默认 `Application.targetFrameRate = 30`，未设置任何覆盖值。  
整个项目 `Assets/Scripts/` 中搜索 `targetFrameRate`、`vSyncCount`：**零匹配**。  
`FpsDisplay.cs` 本身只是计数器，没有设置任何帧率限制，不是问题所在。

### 修复
在 `GameManager.OnSingletonAwake()` 中添加：
```csharp
Application.targetFrameRate = 60;
QualitySettings.vSyncCount = 0; // 部分设备 vsync 会覆盖 targetFrameRate
```

## 问题二：进入第二/三章战斗瞬间 15fps

### 根因
`GameManager.DelayedStartGame()` 调用链：
```
DelayedStartGame()
  → InitializeChapterConfig()
  → ApplyChapterConfig()
      → EnemyPoolManager.InitializeForChapter(chapterIndex)
          → foreach(每种敌人类型)
              → new ObjectPool(..., prewarmCount, ...)  ← 构造函数内同步 Prewarm()
                  → for(0..prewarmCount) Instantiate(prefab)  ← 全部在同一帧执行！
```

第二/三章拥有 7-8 种敌人，每种 prewarm 数 4~12，等于 **单帧内 50~80 次 Instantiate**，叠加 GPU Shader 首次编译（每种新材质/Shader 变体在首次渲染时需 JIT 编译），导致首帧耗时 60~100ms → 15fps。

### 修复
1. 修改 `EnemyPoolManager`：新增 `WarmupCoroutine(instancesPerFrame)`，将预热分散到多帧执行（每帧 2 个实例）。
2. 修改 `GameManager.DelayedStartGame()`：在 `StartGame()` 前 `yield return StartCoroutine(WarmupCoroutine)` 等待预热完成。
3. 同时删除 `InitializeForChapter` 内的同步预热调用（传 `initialSize = 0`），改由协程接管。

---

## 问题三：FindObjectsOfType 在 WaveManager 中每波调用

### 位置
`WaveManager.ProtectDropPhaseRoutine()`（L819）：
```csharp
var crates = FindObjectsOfType<TacticalCrate>();
```
每完成一个波次触发，`FindObjectsOfType` 遍历场景中所有 GameObject，O(n) 开销。

### 修复
改为直接查询 `TacticalDropManager.Instance.IsDropPhase`（O(1)），无需遍历场景。

---

## 已确认 OK / 不需要改动的项目

| 项目 | 结论 |
|------|------|
| `GameLogger.Log()` | `ENABLE_LOG = false`，编译期彻底剥离，无运行时开销 |
| `GameLogger.LogWarning/Error()` | 无 ENABLE_LOG 保护，但仅在异常条件分支触发，不影响正常流程 |
| `FpsDisplay.OnGUI()` | 每帧绘制 1 个 Box + 1 个 Label，极低开销 |
| `EnemyPoolManager` 运行时 Spawn/Despawn | 已用对象池，正确 |
| `FloatingTextManager` | 已用对象池 + 预热，正确 |
| `WaveManager.WaitForClearThenCompleteWave` | 仅 `yield return null` 逐帧轮询，正确 |
| 其余 `FindObjectOfType` 调用 | 大多在场景初始化时执行一次，可接受 |

## 修改文件清单

1. `Assets/Scripts/Logic/GameManager.cs`
   - `OnSingletonAwake()` 添加 targetFrameRate = 60
   - `DelayedStartGame()` 在 StartGame 前 yield warmup 协程

2. `Assets/Scripts/Core/Pool/EnemyPoolManager.cs`
   - `InitializeForChapter()` 改为传 `initialSize = 0`，存储 prewarm targets
   - 新增 `WarmupCoroutine(int instancesPerFrame = 2)`

3. `Assets/Scripts/Logic/WaveManager.cs`
   - `ProtectDropPhaseRoutine()` 替换 FindObjectsOfType

## 附：Unity 编辑器端额外建议（不在代码范围内）

- **PlayerSettings > Android > Default Orientation**：确认已锁定方向（减少重排）  
- **Quality Settings**：移动端关闭 Shadows 和 Anti-Aliasing  
- **ShaderVariantCollection**：预热常用 Shader 变体，消除首帧 GPU 编译毛刺  
- **Texture Compression**：Android 使用 ASTC（更快解码）  
- **IL2CPP**：确认使用 IL2CPP 而非 Mono，运行时性能提升 20-30%
