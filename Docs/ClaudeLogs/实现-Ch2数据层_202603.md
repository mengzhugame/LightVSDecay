# Stage 2：第二章怪物数据层实现

**日期**：2026-03-27
**阶段**：Stage 2 — Ch2 Data Layer

---

## 需求

为第二章（熔岩章节）建立完整的怪物数据层，支持：
- 7 种新怪物类型（分裂者、坦克、爆炸者、炮手、精英×2、熔岩水坑）
- 死亡特殊行为：分裂召唤子单位、死亡留坑
- 新的 AI 行为类型：Stationary（静止障碍）、RangedGunner（远程炮手）
- 无受击闪烁的障碍物配置支持

---

## 修改文件

### 1. `Assets/Scripts/Core/Pool/EnemyPoolManager.cs`

**EnemyType 枚举新增**：
```
LavaSplitter       // 熔岩分裂者
LavaTank           // 熔岩坦克
LavaExploder       // 熔岩爆炸者
LavaGunner         // 熔岩炮手
EliteLavaSplitter  // 精英熔岩分裂者
EliteLavaExploder  // 精英熔岩爆炸者
LavaPuddle         // 熔岩水坑（静止地形）
```

### 2. `Assets/Scripts/Data/SO/EnemyData.cs`

**EnemyBehaviorType 枚举新增**：
```
Stationary    // 静止障碍（熔岩水坑）
RangedGunner  // 远程炮手（熔岩炮手）
```

**新增字段**：
- 死亡分裂：`splitOnDeath`, `splitEnemyType`, `splitCount`
- 死亡留坑：`spawnPuddleOnDeath`, `puddleEnemyType`
- 障碍物设置：`disableHitFlash`, `disableKnockback`

**新增便捷属性**：`IsStationary`, `IsRangedGunner`

### 3. `Assets/Scripts/Logic/Enemy/EnemyBlob.cs`

**运行时字段缓存**：在 `LoadDataFromConfig()` 中加载所有新字段。

**Die() 方法新增逻辑**：
```csharp
// 分裂者：均匀角度生成 N 个子单位
if (splitOnDeath) { ... }
// 爆炸者：原地生成熔岩水坑
if (spawnPuddleOnDeath) { ... }
```

**MoveTowardsTower() 新增分支**：
```csharp
else if (behaviorType == EnemyBehaviorType.Stationary)
{
    rb.velocity = Vector2.zero;  // 强制静止
}
```

**受击闪烁防护**：`if (!disableHitFlash)` 保护，水坑不闪烁。
