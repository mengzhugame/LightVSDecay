## 需求

- 怪物正面独立冰盾（HP 15,000）
- 冰盾存在时：激光完全阻断穿透 / 伤害减少50% / 物理推力衰减80%
- 冰盾破碎后：激光直接打本体，恢复正常减伤（0%）和击退抗性
- 视觉：冰盾存在时本体不缩小；冰盾消失后正常缩小

## 缺失逻辑（本次修改）

### 1. `EnemyBlob.TakeDamage()` — 冰盾伤害折扣 + 击退衰减

**修改前：**
```csharp
if (iceShield != null && iceShield.IsActive)
{
    iceShield.TakeDamage(damage);   // 全额伤害，无击退
    return;
}
```

**修改后：**
```csharp
if (iceShield != null && iceShield.IsActive)
{
    iceShield.TakeDamage(damage * 0.5f);          // 伤害减免50%
    if (canBeKnockedBack)
        ApplyKnockbackByType(knockbackForce * 0.2f); // 推力衰减80%，保留20%
    return;
}
```

### 2. `EnemyBlob` — 新增 `HasActiveIceShield` 属性

供 `LaserController` 查询，判断是否需要阻断穿透：

```csharp
public bool HasActiveIceShield => iceShield != null && iceShield.IsActive;
```

### 3. `LaserController.cs` — 穿透循环阻断

在穿透处理循环的 `IsStationary break` 之后添加：

```csharp
// 冰甲卫士（冰盾存活）：激光打中冰盾后阻断穿透，不击中盾后方目标
if (enemy.HasActiveIceShield)
    break;
```

注意：先调用 `ProcessEnemyHit`（让冰盾吃到伤害），再 break（阻断穿透）。
