## 技能设计 → 代码实现映射

### 技能1：冰墙构建（主动 · 冷却20秒）
- **映射**：`BossState.Summon` → `ExecuteSummonBehavior()`
- 召唤 2~3 堵冰墙（`EnemyType.IceWall`，随机位置）
- 利用 BaseBossController 的 summonCooldown 机制

### 技能2：冰封射线（主动 · 冷却15秒）
- **映射**：自定义协程（覆盖 stateCoroutine + ChangeState(Stun) 停止Boss移动）
- Boss 停止移动，持续 3 秒旋转射线（60°/秒，共180°）
- 每帧 Physics2D.Raycast 检测击中 Tower/Shield
- 命中则调用 `TurretController.Freeze(1.5f)`

### 技能3：极寒冲撞（主动 · 冷却18秒）
- **映射**：`BossState.Charge`（标准）
- `OnChargeDashComplete()` 中调用 `TurretController.Freeze(1.5f)`
- 路径不留持续伤害区域（区别于 Ch2）

### 技能4：绝对零度（高优先 · 冷却30s/12s）
- **映射**：`TriggerAbsoluteZero()` 在 `OnExtraUpdate()` 中检测冷却
- 实现：ChangeState(Stun) 停止Boss → 立即覆盖 stateCoroutine → AbsoluteZeroRoutine
- 3秒蓄力期间跟踪 Boss 受到的伤害
- 打断成功：ForceStun（眩晕）→ Idle
- 打断失败：TurretHealth.TakeTrueDamage(当前HP*30%) + TurretController.Freeze(3s) + 召唤额外怪物波次

## 技能选择权重（ChooseActiveSkill）

优先级顺序：
1. 绝对零度（最高优先，由 OnExtraUpdate 设 absoluteZeroTriggered 标志）
2. 冰封射线（冷却就绪时 40% 概率）
3. 冰墙构建（由基类 summonCooldownReady 驱动，Idle 中中断）
4. 极寒冲撞（兜底）


## 关键实现细节

### 冰封射线物理检测
```
- 射线起点：Boss transform.position
- 射线方向：由当前旋转角度决定（Quaternion.Euler(0,0,angle) * Vector2.down）
- 射线长度：20f（足够穿越屏幕）
- 检测层：Shield | Tower
- 命中：freeze turret（单次触发，冷却内不重复）
```

### 绝对零度伤害追踪
```
- 蓄力开始时记录 hpSnapshot = bossHealth.CurrentHP
- 每帧检测 hpSnapshot - bossHealth.CurrentHP >= interruptThreshold
- 打断后立即取消伤害计算
```

### 阶段2额外 FrostTank 召唤
```
- 计时器 phase2TankTimer -= deltaTime
- 归零时调用 EnemyPoolManager.Instance.Spawn(FrostTank, 随机位置)
- 重置为 phase2TankSummonInterval
```
