# Ch2 怪物音效/特效接入方案分析
**日期**: 2026-03-31
**需求**: 查看 VFXPoolManager 和 AudioManager 是否需要重构，方便接入 Ch2/Ch3 怪物的音效特效；分裂怪死亡接口（可留空）。

---

## 一、现状速览

### VFXPoolManager
- 使用 `VFXType` 枚举 + Inspector 配置列表（`VFXPoolConfig` with `usePool` flag）
- 高频特效走对象池（`EnemySteam`, `EnemyExplosion`, `LaserHit`, `FrostHit`）
- 低频特效直接 Instantiate（`ShieldBreak`, `BossDeath` 等）
- 语义化方法：`PlayEnemySteam()`, `PlayEnemyExplosion()` 等

### AudioManager
- 一个全局 `sfxSource` + `PlayOneShot` 处理所有一次性音效（PlayOneShot 天然支持多个同时播放，无截断问题）
- 所有音效配置集中在 `AudioConfig` ScriptableObject
- 怪物相关方法：`PlayEnemyExplode()`, `PlayEnemyDeath()`, `PlayEnemyFreeze()`
- `PlayEnemyExplode()` 目前被自爆怪（激光击杀/碰撞）共用

---

## 二、是否需要重构？

**结论：两者均不需要重构，只需扩展。**

| 管理器 | 现有问题 | 操作 |
|--------|---------|------|
| VFXPoolManager | 无泛用分裂特效类型 | 新增 `EnemySplit` 枚举值 + 方法 |
| AudioManager | 无分裂死亡音效接口 | AudioConfig 加字段，AM 加方法 |
| EnemyBlob | splitOnDeath 代码块无 VFX/SFX 调用 | 在 splitOnDeath 块末尾添加调用 |

## 三、具体修改计划

### 3.1 VFXPoolManager.cs — 新增枚举值
```csharp
// 在 EnemyExplosion 后添加
EnemySplit,  // 分裂怪死亡爆开（低频，可留空）
```

### 3.2 VFXPoolManager.cs — 新增语义化方法
```csharp
public void PlayEnemySplit(Vector3 position)
{
    Play(VFXType.EnemySplit, position);
}
```

### 3.3 AudioConfig.cs — 新增音效字段
```csharp
[Tooltip("分裂怪死亡爆开音效（可不配置）")]
public AudioClip enemySplit;
```

### 3.4 AudioManager.cs — 新增方法
```csharp
public void PlayEnemySplit()
{
    if (config != null && config.enemySplit != null)
        PlaySFX(config.enemySplit, config.enemyDefaultVolume);
}
```

### 3.5 EnemyBlob.Die() — 在 splitOnDeath 循环末尾加调用
```csharp
if (splitOnDeath)
{
    // ... 现有的 for 循环生成子体 ...

    // 分裂死亡特效/音效（可在 Inspector 留空）
    VFXPoolManager.Instance?.PlayEnemySplit(transform.position);
    AudioManager.Instance?.PlayEnemySplit();
}
```

## 四、Inspector 配置说明

完成代码修改后，用户需要在 Unity Inspector 中：

**VFXPoolManager（对应 GameObject 上）**：
- VFX Configs 列表中新增一条 `EnemySplit` 条目
- `usePool: false`（低频，不需要对象池）
- `prefab`: 分配分裂死亡特效预制体（或留空/不分配）

**AudioConfig（ScriptableObject）**：
- `enemySplit` 字段：分配分裂死亡音效（或留空）

**备注**: `EnemyExplosion` 条目已被自爆怪死亡复用，不需要额外配置。自爆怪音效 = `enemyExplode` 字段（已有）。
