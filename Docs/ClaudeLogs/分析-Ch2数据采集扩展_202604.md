## 一、现有系统盲区（问题清单）

### 1.1 最严重：Ch2敌人类型完全丢失

`SpawnCounter.Add()` 和 `KillCounter.Add()` 的 switch 只覆盖Ch1类型：

```csharp
case EnemyType.Slime:    slime++; break;
case EnemyType.Rusher:   rusher++; break;
case EnemyType.Tank:     tank++; break;
case EnemyType.Drifter:  drifter++; break;
case EnemyType.EliteTank:
case EnemyType.EliteDrifter: elite++; break;
// ↑ 没有 default → Ch2所有类型悄无声息地丢弃
```

**Ch2实际存在的EnemyType（全部未被记录）：**

| EnemyType | 中文名 | 现状 |
|---|---|---|
| `LavaSplitter` | 熔岩分裂者 | ❌ 丢失 |
| `LavaTank` | 熔岩坦克 | ❌ 丢失 |
| `LavaExploder` | 熔岩爆炸者（自爆怪）| ❌ 丢失 |
| `LavaGunner` | 熔岩炮手 | ❌ 丢失 |
| `EliteLavaSplitter` | 精英熔岩分裂者 | ❌ 丢失 |
| `EliteLavaExploder` | 精英熔岩爆炸者 | ❌ 丢失 |
| `LavaPuddle` | 熔岩水坑 | ❌ 丢失 |

`WaveStatData` 的 CSV字段（Kill_Slime/Kill_Rusher/Spawn_Slime等）也没有Ch2对应列，**第二章的击杀/生成数据整列为0**。

### 1.2 伤害来源混淆

**问题A：炮手子弹被归入BossBullet**

```csharp
// LavaProjectile.cs（炮手子弹）
BattleStatistics.Instance.RecordPlayerDamage(damage, PlayerDamageSource.BossBullet);
//                                                     ^^^^^^^^^ 应该是MobBullet
```

炮手是普通怪，不是Boss，但子弹伤害混入 `bossDmgBullet` 字段，导致Boss战数据失真。

**问题B：自爆AoE伤害和普通碰撞混在一起**

```csharp
// EnemyBlob.TriggerExplosionAoE()
BattleStatistics.Instance?.RecordPlayerDamage(explosionAoeDamage, PlayerDamageSource.MobCollision);
//                                                                  ^^^^^^^^^^^^^^^^^ 无法区分爆炸和碰撞
```

无法分析"自爆怪的AoE伤害占总小怪伤害比例"——这是Ch2数值平衡的核心指标。

### 1.3 Ch2特有机制完全没有采集

| 机制 | 触发位置 | 现有记录 |
|---|---|---|
| 自爆怪死亡触发AoE | `EnemyBlob.OnDeath → TriggerExplosionAoE` | ❌ 无次数统计 |
| 自爆怪死亡生成熔岩水坑 | `EnemyBlob.OnDeath → spawnPuddleOnDeath` | ❌ 无水坑生成记录 |
| 分裂怪死亡分裂 | `EnemyBlob.OnDeath → splitOnDeath` | ❌ 无分裂次数/子体数 |
| 炮手开火 | `LavaGunnerAI.cs` | ❌ 无射击次数 |
| 炮手子弹命中 | `LavaProjectile.cs` | ⚠️ 混入BossBullet |
| 熔岩水坑在场数量 | 无实时追踪 | ❌ 完全空白 |
| Boss吸收小怪回血 | `VolcanoBossController → HealHP` | ❌ 无回血量记录 |
| Boss陨石攻击 | `VolcanoMeteor.cs` | ⚠️ 混入summonCount |
| Boss熔浆弹 | `BossPollutionProjectile → LavaProjectile` | ⚠️ 已记录但和炮手弹混淆 |

## 二、数据建模需要的锚点

第二章数值平衡需要回答以下问题，对应需采集的字段：

| 分析问题 | 所需字段 |
|---|---|
| 炮手怪实际存活多久，输出弹数是否合理？ | 炮手击杀数、炮手开火次数 |
| 自爆怪的爆炸是否造成显著威胁？ | 自爆AoE次数、自爆对玩家伤害 |

| 炮手子弹 vs Boss技能，哪个对玩家伤害更大？ | MobBullet vs BossBullet 分离 |
| 波次难度斜率是否合理（自爆+分裂组合）？ | 按波次统计以上所有指标 |

## 七、水坑峰值数量追踪方案

水坑是动态生成/消亡的，需要实时追踪。推荐方案：

**在 `EnemyPoolManager` 或 `BattleStatistics.Update()` 中统计活跃水坑数**：

```csharp
// BattleStatistics.Update() 中
int currentPuddleCount = EnemyPoolManager.Instance?.GetActivePuddleCount() ?? 0;
if (currentPuddleCount > _wavePuddlePeakCount)
    _wavePuddlePeakCount = currentPuddleCount;
```

需要 `EnemyPoolManager` 新增 `GetActivePuddleCount()` 方法（返回当前场上活跃的LavaPuddle数量）。
