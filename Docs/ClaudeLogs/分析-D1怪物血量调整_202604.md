## 二、各章根因分析

### Ch1 D1：整体健康，轻微优化

**数据事实：**
- W1–W4 两局均零受伤
- W5 受伤仅 330–540，护盾完全吸收或只剩少量本体伤害
- BOSS：26s（快）/ 129s（慢），两局均通关

**结论**：Ch1 D1 **本身不是问题**，但小白玩家（比你更不熟悉操作）在 W5 大密度时可能会有压力。  
**推荐**：`enemyHealthMultiplier 1.0 → 0.80`，轻降给喘息空间，不改变游戏感受。

---

### Ch2 D1：根因是"LavaSplitter 分裂子体"造成的连锁伤害

**数据事实（败局 163722）：**

| 波次 | 开始HP | 结束HP | 本波受伤 | 命中次数 | 说明 |
|---|---|---|---|---|---|
| W1 | 护盾1000 / 本体2000 | 护盾100 / 本体2000 | **护盾-900** | 30次 | 16只分裂者，命中30次！ |
| W2 | 护盾100 / 本体2000 | 护盾0 / 本体1940 | 160 | 6次 | 护盾耗尽 |
| W3 | 护盾0 / 本体1940 | 护盾0 / 本体1910 | 30 | 1次 | |
| W4 | 护盾0 / 本体1910 | 护盾0 / 本体1760 | 150 | 5次 | |
| **W5** | **护盾0 / 本体1760** | **0 / 0** | **1775（死亡）** | 46次/27s | 直接被淹没 |

**根因链：**
```
W1 LavaSplitter 16只 → 死亡时各分裂出2只子体 → 场上突增32只子体
→ 低等级玩家无法快速清场 → 子体接触伤害疯狂堆叠
→ 命中30次 / 护盾几乎耗光
→ W2起裸血运行，容错归零
→ W5 53只怪涌入 → 27秒内死亡
```

**对比胜局（112629）**：使用 Frost+Shatter 的玩家，Shatter技能在冰冻敌人上触发爆炸，AOE 秒杀 Splitter 及其子体，所以 W1 只受 400伤害且都靠护盾吸收。

**核心结论**：Ch2 D1 最危险的不是单体血量而是**分裂子体爆发数量**。降低血量 = 更快击杀 Splitter → 子体出现前已死 → 连锁伤害被切断。

**推荐**：`enemyHealthMultiplier 1.0 → 0.60`（大幅降低，从根源切断子体连锁）

---

### Ch3 D1：小怪血量合理，BOSS是问题

**数据事实（114403）：**
- W1–W5 **零受伤**，说明冰霜小怪 HP 对 D1 玩家完全友好
- **BOSS 战时长 223.9s**，严重超过设计上限 90s（策划案：55–70s）
- Lv16 进入 BOSS（目标 Lv17），Panel_DPS 仅 2760

**结论**：Ch3 D1 **小怪血量无需调整**，BOSS问题是另一个任务（本次不动）。

## 三、调整方案（量化推导）

### 调整旋钮：`enemyHealthMultiplier`

#### Ch2 D1 计算验证（关键章节）

**目标**：Lv1（1000 DPS）在 W1 能在 0.5s 内击杀单只 Splitter，让其在接触前被消灭。

| 参数 | 当前 | 调整后(0.60×) |
|---|---|---|
| Splitter HP（推算：12000÷16=750） | 750 | **450** |
| TTK @Lv1 DPS 1000 | 0.75s | **0.45s** |
| 子体HP（约Splitter 50%） | 375 | **225** |
| 子体TTK @Lv1 1000DPS | 0.375s | **0.225s** |

0.45s TTK + 子体 0.225s 即死 → Splitter被秒 + 子体被秒 → W1 命中次数从 30次 → 预计 < 10次 → 护盾损耗从 900 → 预计 < 300。

#### Ch1 D1（参考）

| 参数 | 当前 | 调整后(0.80×) |
|---|---|---|
| 粘液 HP 1000 | 1000 | 800 |
| TTK @Lv1 DPS 1000 | 1.0s | 0.8s |
| 坦克 HP 9200 | 9200 | 7360 |
| TTK @Lv7 DPS ~2000 | 4.6s | 3.7s |

感受：粘液更脆，坦克减少1秒等待，爽感↑。

## 四、最终方案

| 章节 | 当前 | 调整后 | 理由 |
|---|---|---|---|
| Ch1 D1 | `enemyHealthMultiplier: 1.0` | **0.80** | 轻微优化，给小白喘息空间 |
| Ch2 D1 | `enemyHealthMultiplier: 1.0` | **0.60** | 切断Splitter子体连锁，从根本解决死亡问题 |
| Ch3 D1 | `enemyHealthMultiplier: 1.0` | **不变** | W1-W5零受伤，小怪不是问题 |

**BOOS HP 不动**（独立旋钮，本次范围外）。
