# 激光长度上限系统 — 修改方案

**日期**: 2026-03-30
**需求**: 激光总长度（技能 + 无人机叠加）可达 40+，超出屏幕范围。设定硬上限并实现溢出转伤害机制。

---

## 一、现状分析

### 数据基线

| 参数 | 当前值 |
|------|--------|
| `GameSettings.maxLaserLength`（基础长度） | 20 |
| `skillLengthMultiplier`（初始值） | 1.0 |
| `CurrentLaserLength` 公式 | `20 × skillLengthMultiplier` |
| 副激光长度公式 | `CurrentLaserLength × subLaser.lengthMultiplier` |

### 两大增长来源

**来源1 — 反射透镜技能（累积叠加，每次升级都 ADD）**

| 等级 | reflexLengthBonus | 叠加后 skillLengthMultiplier | CurrentLaserLength |
|------|-------------------|-----------------------------|--------------------|
| L1 | 0 | 1.00 | 20 |
| L2 | +0.10 | 1.10 | 22 |
| L3 | +0.20 | 1.30 | 26 |
| L4 | +0.40 | 1.70 | 34 ← 超屏 |
| L5 | +0.60 | 2.30 | 46 ← 严重超屏 |

**来源2 — 无人机三选一奖励（每次选择 +10%）**

- `type: 7 (LaserLengthPercent)`, `value: 0.1` → 每次 +2 单位
- 一局游戏可触发多次，与技能叠加无上限

### 问题根源

`AddLengthPercent()` 只有下限保护（80%），没有上限截断。
技能升级 + 无人机奖励双重叠加，最终 skillLengthMultiplier ≥ 2.0，激光达 40+。

---

## 二、目标设计

| 激光类型 | 最大长度（世界单位） |
|----------|---------------------|
| 主激光   | **29** |
| 副激光   | **26** |

达到上限后的行为：
- 技能 / 无人机的"增加长度"选项 → **转换为激光伤害加成**（1% 溢出长度 → +2% 伤害）
- 无人机选项池：当主激光已达 29，`LaserLengthPercent` 条目**从选项池中移除**

## 三、修改方案

### 3.1 LaserController.cs — 添加硬上限 + 溢出转伤害

**修改点**：`AddLengthPercent()` 方法

```csharp
// 新增常量（或 Inspector 字段）
public const float MAIN_LASER_LENGTH_CAP = 29f;
public const float SUB_LASER_LENGTH_CAP  = 26f;
private const float OVERFLOW_TO_DAMAGE_RATIO = 2f; // 1% 溢出 → 2% 额外伤害

// 新增属性
public bool IsMainLaserAtLengthCap => CurrentLaserLength >= MAIN_LASER_LENGTH_CAP - 0.01f;

// 修改 AddLengthPercent()
public void AddLengthPercent(float percent, float minPercent = 0.8f)
{
    float newMultiplier = skillLengthMultiplier + percent;
    if (newMultiplier < minPercent) newMultiplier = minPercent;

    float maxAllowedMultiplier = MAIN_LASER_LENGTH_CAP / maxLaserLength;

    if (percent > 0)
    {
        if (skillLengthMultiplier >= maxAllowedMultiplier)
        {
            // 已达上限，全部转为伤害
            damageCalculator.AddDropBonusDamagePercent(percent * OVERFLOW_TO_DAMAGE_RATIO);
            return;
        }

        if (newMultiplier > maxAllowedMultiplier)
        {
            // 部分转为伤害
            float overflowPercent = newMultiplier - maxAllowedMultiplier;
            damageCalculator.AddDropBonusDamagePercent(overflowPercent * OVERFLOW_TO_DAMAGE_RATIO);
            newMultiplier = maxAllowedMultiplier;
        }
    }

    skillLengthMultiplier = newMultiplier;

    // 更新主激光
    mainLaserBeam?.SetMaxLength(CurrentLaserLength);

    // 更新副激光（同样有上限）
    foreach (var subLaser in subLasers)
    {
        float rawSubLen = CurrentLaserLength * subLaser.lengthMultiplier;
        float cappedSubLen = Mathf.Min(rawSubLen, SUB_LASER_LENGTH_CAP);
        subLaser.beam?.SetMaxLength(cappedSubLen);
    }
}
```

> **注意**：需要确认 `damageCalculator.AddDropBonusDamagePercent()` 方法是否已存在，如没有则新增。

### 3.2 TacticalDropManager.cs — 无人机选项池过滤

在构建奖励选项池时，当主激光已达上限则过滤掉长度增加选项。

```csharp
// 在 BuildRewardPool() 或 GetAvailableRewards() 中添加：
bool laserAtLengthCap = LaserController.Instance != null
    && LaserController.Instance.IsMainLaserAtLengthCap;

if (laserAtLengthCap)
{
    rewardPool.RemoveAll(r => r.type == RewardType.LaserLengthPercent);
    GameLogger.Log("[TacticalDrop] 激光长度已达上限，已从奖励池移除「激光长度」选项");
}
```

### 3.3 Skill_Reflex.asset — 重新设计 reflexLengthBonus 数值

**旧设计问题**：L4/L5 的增量过大（单次 +0.4 / +0.6），L4 已超上限 45%。
**新设计原则**：每次升级的增量均匀，L5 满级后恰好触达或刚好达到上限，溢出部分由上限机制自动转为伤害。

| 等级 | reflexLengthBonus（增量） | 累积后 skillLengthMultiplier | CurrentLaserLength |
|------|--------------------------|-----------------------------|--------------------|
| L1 | 0 | 1.00 | 20（无加成，仅开启反射） |
| L2 | **+0.10** | 1.10 | 22 |
| L3 | **+0.15** | 1.25 | 25 |
| L4 | **+0.20** | 1.45 | **29（触达上限）** |
| L5 | **+0.20** | 1.45（capped） | **29（满）** + 额外 +40% 伤害 |

- L5 额外 +0.20 × OVERFLOW_TO_DAMAGE_RATIO(2) = **+40% 激光伤害**
- 技能说明文本 L5 可改为："反射段伤害100%，激光已达最大长度，**额外获得+40%伤害**"

### 3.4 DroneRewardConfig.asset — LaserLengthPercent value 调整

当前 value = 0.1（+10%，每次 +2 单位）。保持不变即可，上限机制会自动处理溢出。
无需修改数值，但如果希望"早期加长有意义"，可考虑下调为 0.07（+7%，约 +1.4 单位）。

## 四、需要确认的技术细节

1. **`damageCalculator.AddDropBonusDamagePercent()` 是否已存在？**
   → 若不存在，需在 DamageCalculator 新增此方法

2. **Reflex 技能升级时是否重置上次加的长度？**
   → 当前代码看起来是累积叠加（每次升级都 ADD，不 SUB 上次值）
   → 需要检查并修正为：升级时先减去上次 bonus，再加新 bonus
   → 或者在 SkillEffectManager 追踪 `lastAppliedReflexLengthBonus`

3. **副激光 lengthMultiplier 当前实际值是多少？**
   → Prism / Focus 技能创建的副激光，其 `subLaser.lengthMultiplier` 基于 `splitLength / maxLaserLength`
   → `splitLength = 3` → 倍率 = 0.15 → 副激光仅 3 单位？需确认

4. **TacticalDropManager 的 BuildRewardPool 具体在哪个方法中？**
   → 需要找到正确的注入点
