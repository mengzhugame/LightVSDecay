  ---
  技术机制

  控制旋钮只有一个：DifficultySettings.enemyHealthMultiplier。

  它作用于所有普通怪物（BOSS 有独立的 bossHealthMultiplier，不受影响）。当前 D1 = 1.0（满血），设为 0.75 意味着怪物只有原本 75%
  的血量。

  ---
  核心公式：TTK（击杀时间）

  ▎ 目标 TTK = 怪物 HP ÷ 玩家期望 DPS

  对 D1 来说，合理的"爽感区间"是：
  - 粘液类（炮灰）：0.5–1.5 秒/只（激光扫过去就碎）
  - 坦克类（硬骨头）：4–7 秒/只（需要持续照射，但不会卡太久）

  用战报验证现状（无 exp 修复前，Lv12 时）

  ---
  结论：要不要降血量？

  真实根因已经被 exp 修复解决了。 W5 的挫败感来自 Lv12 技能不足，而不是怪物血量。

  但如果你仍然希望降血量（让 W1–W3 早期阶段也更轻松），可以设 enemyHealthMultiplier = 0.75：

根因：代码 Bug，不是配置问题

  WaveManager.ApplyDifficultyModifiers() 里，读取了 chapterHealthMult = 0.6 但下面构建怪物属性时根本没用上它：

  // 修复前（有 bug）：chapterHealthMult 读了但没乘
  hpMultiplier = waveDifficulty * extraHealthMult  // 章节倍率完全缺失

  // 修复后：
  hpMultiplier = waveDifficulty * chapterHealthMult * extraHealthMult

  所以不管你在配置文件里填 0.6 还是 0.1，怪物血量一直是满额的，enemyHealthMultiplier 这个字段对所有章节/难度都是死参数。

  顺带修复的：chapterSpeedMult 也有同样的 bug，速度倍率同样从未生效——现在 D2–D5 的速度加成也会真正起作用了。

  LavaSplitter 子体不需要额外处理——子体通过 child.SetWaveModifiers(waveModifiers) 继承父体的
  waveModifiers，修好父体的倍率计算后，子体自动跟着降到 450 HP。

  重新进游戏测试 Ch2 D1，W1 那波 16 只分裂者应该明显更脆了。

 无人机三选一：头顶标题标签实现方案

 Context（背景）

 玩家在无人机三选一阶段，只能通过宝箱颜色（蓝/金/紫）区分三种无人机，无法快速理解各自的功能定位。需要在每个无人机头顶添加标题标签，让

 三、技术实现方案

 步骤 1：TacticalCrate.cs 新增标题字段

 在 TacticalCrate.cs 中新增：
 [Header("标题标签")]
 [SerializeField] private TextMeshProUGUI titleLabel;

 在 Initialize(CrateType type, int hp) 方法内，按类型设置文字和颜色：
 if (titleLabel != null)
 {
     switch (type)
     {
         case CrateType.Supply: titleLabel.text = "生命补给"; titleLabel.color = supplyColor; break;
         case CrateType.Gacha:  titleLabel.text = "命运空投"; titleLabel.color = gachaColor;  break;
         case CrateType.Deal:   titleLabel.text = "等价交换"; titleLabel.color = dealColor;   break;
     }
 }

 颜色复用 DroneRewardConfig 中现有的颜色定义：
 - Supply → supplyTextColor（蓝绿色 #66E5FF）
 - Gacha → epicColor（金色 #FFD700）
 - Deal → negativeColor（红色 #FF4D4D）

 步骤 2：三个 Prefab 中添加 TextMeshProUGUI

 在 Unity Editor 中，对每个 Crate Prefab（ProgressCanvas 下）新增子节点：
 ProgressCanvas
 ├── CrateProgressUI（现有）
 └── TitleLabel（新增 TextMeshProUGUI）
     ├── 锚点位置：(0, 0) 本地坐标系 Y = +1.8（宝箱头顶上方）
     ├── 字体大小：28
     ├── 对齐：水平居中 / 垂直居中
     ├── 颜色：由代码动态设置
     └── 字体：复用现有 FillText 的字体资源

 将 TitleLabel 拖拽绑定到 TacticalCrate 的 titleLabel 字段。

 步骤 3：验证

 - 进入战斗，等待波次结束触发无人机空投
 - 三个无人机落地后，头顶应显示对应颜色的标题文字
 - 检查文字位置不与进度条重叠
 - 宝箱消失（Vanish / Die）时标题随宝箱整体消失（无需额外处理，挂在子节点上自动跟随）
