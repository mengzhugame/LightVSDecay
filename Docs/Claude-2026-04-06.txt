  ---
  关于是否使用 Animator 组件？

  推荐：不用 Animator，用代码驱动（Coroutine + AnimationCurve）

  原因：

  1. 项目一致性 — 当前所有 Boss/怪物的动画逻辑都是 Coroutine 驱动（FreezeCoroutine、ChargeCoroutine 等），风格统一
  2. 零额外资产 — Animator 需要创建 .controller、.anim clip 文件；Coroutine 只需一个 MonoBehaviour
  3. 数值易调整 — 飞入距离、时长、缓动曲线直接在 Inspector 的 AnimationCurve 字段拖拽调节，设计师友好
  4. 触发简单 — 代码里直接调 bossWarningUI.Show()，不需要维护 Animator 状态机

  什么时候才用 Animator？
  如果动画有多个状态循环（如 Idle → Alert → Attack 循环），Animator 才发挥优势。这个横幅是「一次性播放然后消失」，不值得引入状态机复杂度。

  ├── Hide()          → 触发淡出协程

  - 峰值DPS：[peakDPS]  均值DPS：[avgDPS]
  - 激光有效命中率 = totalDamageDealt / (totalDamageDealt + estimatedMissedDamage)
  - 大招DPS占比 = overloadDamage / totalDamageDealt

  【第三章特有压力指标】
  - 冻结总时长：[towerFreezeTotalDuration]s（DPS损失窗口）
  - 冰墙被摧毁/自然消失 = [iceWallDestroyedCount] / [iceWallExpiredCount]
    → 若自然消失 > 摧毁，说明玩家倾向忽略冰墙
  - 绝对零度打断率 = [absoluteZeroInterruptCount] / [absoluteZeroCastCount]
    → 建议打断率 > 60%，否则真伤过于频繁
  - 催化者BUFF伤害占比 = [damageFromBuffedEnemy] / [totalPlayerDamageReceived]

  【TTK校验】
  对照目标区间：
  - FrostSlime：0.3s~0.8s
  - FrostcasterAI：1.5s~4s
  - FrostEliteTank（冰盾期）：4s~8s
  - GlacialBoss总时长：45s~75s

  【波次节奏】
  逐波列出：[wave_N_startHP] → [wave_N_endHP]，护盾变化，是否触发冻结

  【重点关注问题】
  1. 哪一波伤害突增/突降超过30%？
  2. Boss冰封射线命中塔（穿透护盾）频率是否超过每分钟2次？
  3. 绝对零度真伤是否超过总玩家伤害的15%？
  4. 催化者BUFF扩散是否在波次中制造了不可控的伤害峰值？
