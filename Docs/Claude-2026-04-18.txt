 二、当前 D2-D5 机制缺陷分析

 现状：经验压缩 = 体验伤害

 当前公式：实际收益XP = 怪物XP × expDropMultiplier
 当前配置：
   D2: countMult=1.15, expDrop=0.87  → 1.15×0.87 = 1.001x XP（基本与D1持平）
   D3: countMult=1.30, expDrop=0.77  → 1.30×0.77 = 1.001x XP
   D4: countMult=1.45, expDrop=0.69  → 1.45×0.69 = 1.001x XP
   D5: countMult=1.60, expDrop=0.63  → 1.60×0.63 = 1.008x XP

 设计意图：通过 XP 压缩保证总收益不变，维持 W9=Lv17 锚点。
 实际问题：
 1. 高难度多杀了 30%~60% 怪物，但每只怪 XP 被砍，杀怪"不划算"感
 2. D3 实测达到 Lv19/270（超出 Lv17 目标），说明数学补偿不精确
 3. 玩家感受不到"经验增长"的爽感，高难度失去正向反馈

 新方案：升级门槛随难度线性提升

 新公式：升级所需XP = (expBase + (level-1) × expGrowth) × playerLevelUpExpMultiplier
 新配置（expDropMultiplier 全部改为 1.0）：
   D1: countMult=1.00, expDrop=1.0, playerExpMult=1.00
   D2: countMult=1.15, expDrop=1.0, playerExpMult=1.15
   D3: countMult=1.30, expDrop=1.0, playerExpMult=1.30
   D4: countMult=1.45, expDrop=1.0, playerExpMult=1.45
   D5: countMult=1.60, expDrop=1.0, playerExpMult=1.60

 数学验证（D3 为例）：
 - D1 W1-9 总 XP ≈ 6,736（实测）
 - D3 怪物数×1.30 → 总 XP ≈ 6,736 × 1.30 = 8,757
 - 升级门槛×1.30 → 到达 Lv17 需要 XP ≈ 7,600 × 1.30 = 9,880
 - 差额 9,880-8,757=1,123，有轻微余量，W9 结束仍在 Lv17 附近 ✅

 体验变化：
 - 高难度杀更多怪 → 每只全额 XP → 杀怪爽感不损失
 - 但升级需要更多 XP → 自然放慢升级节奏
 - 玩家感知：「杀了好多怪，怎么还没升级？」→ 促进反复挑战感
