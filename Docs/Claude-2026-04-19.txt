关于光与朽游戏的大招技能的新手引导，玩家初次进入游戏，先经过滑动的引导，然后等大招技能按钮能量积攒满了以后，会有大招的新手引导，现在的问题有2个，第一个是否需要再大招能量快满之前会涌入大量小怪，让玩家可以快速感受到使用大招割草的快感？（担心的有几个问题，需要计算出第一次大招技能快满的时间，然后根据这个时间提前生成很多小怪。另外一个问题是如果这些小怪有经验的话，是否会影响我们之前做好的关于每个章节升级节奏？所以是否这批生成单独的小怪是没有经验或者1点经验，金币是正常的，只是让玩家感受到大招的刺激和快感？）。第二个问题是，大招技能可以让激光长度+3，但是我发现索敌没有根据激光长度进行，就是屏幕顶部已经有小怪了，激光的长度也已足够，但是大招技能没有索敌，感觉索敌没有根据已增加的激光长度进行。先进行新手引导大招生成小怪的方案规划，等我确认好方案后，再修改代码。


计划：新手引导大招前置小怪涌入系统

 Context

 需求背景：
 玩家首次进入游戏，完成激光拖动引导后，等待大招能量积攒满（约60秒）触发大招引导。
 当前问题：大招就绪时屏幕上没有足够的怪物，玩家放出大招感受不到"万怪齐杀"的割草爽感。

 期望效果：
 在大招能量约83%（约50秒）时，屏幕顶部涌入15只小怪，保持存活到大招就绪。
 玩家看到手指引导提示 → 点击大招 → 5秒内扫光这批小怪 → 体验到强烈的大招割草快感。

 用户确认的设计决策：
 - XP = 0（不影响 W9=Lv17 升级节奏锚点）
 - 金币 = 正常（作为正向击杀反馈）
 - 死亡计入当前波次击杀数（实现简单，UX无感知）

 关键系统数值（已探查）：
 - 大招充能：纯时间机制，chargeTime = 60f 秒（OverloadManager.cs:50）
 - 大招激活：5秒，伤害×2，宽度×2，自动瞄准（OverloadManager.cs:54-65）
 - 引导触发条件：OnOverloadStateChanged(Ready) 事件（BattleTutorialDirector.cs:101）
 - WaveManager.OnEnemyDied 有状态守卫：仅在 Spawning/Battle 状态才计数（WaveManager.cs:208）

 新增 PreUltimateSpawnRoutine() 协程：
 private IEnumerator PreUltimateSpawnRoutine()
 {
     // 等待 OverloadManager 初始化
     while (OverloadManager.Instance == null) yield return null;

     // 等到充能进度达阈值
     while (OverloadManager.Instance.ChargeProgress < preUltimateSpawnThreshold)
         yield return null;

     // 如当前是活跃波次，通知 WaveManager 增加计数，避免提前完成
     WaveManager.Instance?.AddBonusEnemyCount(preUltimateSpawnCount);

     // 计算屏幕顶部的世界坐标生成区域
     Camera cam = Camera.main;
     float spawnY = cam.ViewportToWorldPoint(new Vector3(0.5f, 1.05f, cam.nearClipPlane)).y;
     float leftX  = cam.ViewportToWorldPoint(new Vector3(0.08f, 0f, cam.nearClipPlane)).x;
     float rightX = cam.ViewportToWorldPoint(new Vector3(0.92f, 0f, cam.nearClipPlane)).x;

     // 分批生成，产生"涌入"的动感
     for (int i = 0; i < preUltimateSpawnCount; i++)
     {
         float t = preUltimateSpawnCount > 1 ? (float)i / (preUltimateSpawnCount - 1) : 0.5f;
         float x = Mathf.Lerp(leftX, rightX, t) + Random.Range(-0.4f, 0.4f);
         Vector3 spawnPos = new Vector3(x, spawnY, 0f);

         EnemyBlob enemy = EnemyPoolManager.Instance?.Spawn(EnemyType.Slime, spawnPos);
         if (enemy != null)
             enemy.SetXPReward(0); // 0经验，不影响升级节奏；金币保持正常

         yield return _spawnIntervalWait;
     }

     _preUltimateSpawnCoroutine = null;
 }

 修改 OnGameEnd()——补充停止协程：
 private void OnGameEnd()
 {
     _shouldShowLaserTutorial    = false;
     _shouldShowOverloadTutorial = false;
     DestroyCurrent();

     if (_preUltimateSpawnCoroutine != null)
     {
         StopCoroutine(_preUltimateSpawnCoroutine);
         _preUltimateSpawnCoroutine = null;
     }
 }

 _spawnIntervalWait 缓存位置——在 Start() 协程的 yield return null 后赋值：
 _spawnIntervalWait = new WaitForSeconds(spawnInterval);
 （需将字段从 readonly 改为普通私有字段）

 文件 2（最小修改）：Assets/Scripts/Logic/WaveManager.cs

 在公共属性区域（第105行附近）添加：
 /// <summary>
 /// 向当前波次追加额外击杀目标数（教学引导专用）。
 /// 仅在 Spawning/Battle 状态下生效；其他状态额外击杀不计入波次，无需调整。
 /// </summary>
 public void AddBonusEnemyCount(int count)
 {
     if (currentState != WaveState.Spawning && currentState != WaveState.Battle) return;
     totalEnemiesInWave += count;
 }
