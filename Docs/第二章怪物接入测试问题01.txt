  关于 Lava_BossConfig.asset 的问题：

  这是正常的，不是 Bug。解释如下：

  BossConfig 是三章 Boss 共用的基础行为配置类，对应 BaseBossController 里的所有通用机制（入场、待机游走、狂暴、Charge
  冲撞、Press 激光角力、霸体递减等）。每章的 Boss 都需要这些字段，因此 Lava_BossConfig.asset
  里有"看起来像第一章"的字段是正确的——它们是所有 Boss 共享的行为参数，只是数值不同。

  Ch2 专属机制（陨石、汲取融合、绝境碾压）不在 BossConfig 里，它们是 VolcanoBossController 组件自身的 [SerializeField]
  字段，配置在预制体的 Inspector 面板上，不走 ScriptableObject。

  对应关系如下：

  ┌────────────────────────────┬────────────────────────────────────────────┬────────────────────────────┐
  │          参数位置          │                    内容                    │         在哪里配置         │
  ├────────────────────────────┼────────────────────────────────────────────┼────────────────────────────┤
  │ Lava_BossConfig.asset      │ 通用行为：血量、待机、冲撞、角力、狂暴阈值 │ ScriptableObject Inspector │
  ├────────────────────────────┼────────────────────────────────────────────┼────────────────────────────┤
  │ VolcanoBossController 组件 │ 陨石参数、汲取融合参数、绝境碾压参数       │ 预制体 Inspector 面板      │
  └────────────────────────────┴────────────────────────────────────────────┴────────────────────────────┘

  所以你只需要在制作好的 Boss 预制体上，找到 VolcanoBossController 组件，填写那几组
  [Header("陨石喷发")]、[Header("汲取融合")]、[Header("绝境碾压")] 下的字段即可，Lava_BossConfig.asset 不用改结构。

  - 分裂怪：父体触发 TriggerEnemyDied → 协程启动 → 子体生成并登记到池 → 子体逐一死亡 → 全部入池后 active == 0 → 波次完成
