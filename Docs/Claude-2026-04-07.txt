 Q3：Boss战时长推荐区间

 推荐：35 ～ 65 秒（而非用户提出的30-60秒，理由见下）
 - 当前实测：爆发流 14-30s 击杀，冰冻流无法击杀 → 方差太大

 - 65s 上限：冰冻流经过修正后的合理上限，不会让玩家感到拖拉
 - 目标中位：约 50 秒（大多数均衡流派的体验点）

 C. 冰冻流修复（过弱）

 根本问题：Boss 回血量远大于冰冻流 DPS

 修复方向：
 1. 加 Boss 总回血上限（最关键）：Boss 全场累计回血 ≤ Boss最大HP × 40% = 112,000。防止冰霜流数学无解。
   - 修改位置：VolcanoBossController.cs 的 OnAbsorptionComplete() 或 absorb 逻辑中加 totalHealedHP 累计判断
 2. 提升 Shatter Lv5 对冰冻单位的基础加成：+120% → +180%（与击杀爆炸质变分离，纯粹提升 DPS 窗口）
 3. Frost Lv5 对 Boss 冻结持续时间：从 2s → 3s（让 Shatter 窗口更稳定）
 4. 验证冻结积累机制：确认 FrostSpread Lv5 的 50% 冻结积累对 Boss 是否有效（如被特殊免疫需修复）

 冰冻流修复后理论DPS：基础 1,000 × (1+1.8) = 2,800 DPS，+冰冻持续保障后约 4,200-5,000 有效DPS → 280,000 ÷ 4,600 ≈ 61s（满足≤65s上限）

 根本原因（代码层确认）

 Bug 1：Boss 每 Tick 被激光多次命中（暴击流过强的真正原因）

 文件：LaserController.cs，ProcessBossBodyHit()，第 737-740 行

 // 当前代码：只记录，但不阻止多次伤害！
 if (!hitBosses.Contains(bossHealth))
 {
     hitBosses.Add(bossHealth);
 }
 // 之后继续执行伤害逻辑 ← 每个 Boss 碰撞体都会独立造成完整伤害

 原理：
 - hitBosses.Clear() 每 Tick 调用一次（第 339 行）——重置机制存在
 - 但当前代码仅追踪已命中 Boss，不阻止后续碰撞体的伤害
 - Focus Lv5：penetrationCount = -1（无限穿透），激光每 Tick 穿过 Boss 所有碰撞体
 - Boss 有多个身体碰撞体（约 3 个），每 Tick 造成 3× 伤害

 验证：
 - 面板 DPS = 4,576；实际 Boss DPS = 14,567 = 3.18× 面板 DPS
 - 若 Boss 有 3 个碰撞体：4,576 × 3 × 1.25（暴击均值）= 17,160 ≈ 实测 14,567 ✓

 此前为何 Power/Crit 削弱无效：
 - 本次测试玩家用的是 Impact（非 Power）→ Power 削弱毫无影响
 - Crit 伤害 0.9→0.6：仅影响 8% 平均 DPS，远小于 3× Bug 带来的增幅

 修改 1：修复 Boss 多次命中 Bug（P0）

 文件：Assets/Scripts/Logic/Player/LaserController.cs，ProcessBossBodyHit()，第 735-740 行

 // 修改前
 if (bossHealth == null) return;

 if (!hitBosses.Contains(bossHealth))
 {
     hitBosses.Add(bossHealth);
 }

 // 修改后
 if (bossHealth == null) return;
 if (hitBosses.Contains(bossHealth)) return;  // ← 关键：每 Tick 只命中 Boss 一次
 hitBosses.Add(bossHealth);

 同理，ProcessBossEyeHit() 第 684-686 行做同样处理：
 if (hitBosses.Contains(bossHealth)) return;
 hitBosses.Add(bossHealth);

 ▎ hitBosses.Clear() 已在每 Tick 开始时调用（第 339 行），此修改安全。

 修改 2：让 Shatter 对 Boss 生效（P0）

 文件：Assets/Scripts/Logic/Player/LaserController.cs，ProcessBossBodyHit()

 在主伤害代码块之后、ApplyBossFrostEffect 调用之前，新增：

 // 数据破碎（Shatter）加成：仅在 TrueDamageToBoss 激活 + Boss 被减速时触发
 // 设计意图：ice build（Frost 减速）才能触发；burst build（无 Frost，IsSlowed=false）不触发
 if (penetrationHandler.TrueDamageToBoss && bossController.IsSlowed)
 {
     float shatterBonus = SkillEffectManager.Instance?.GetShatterDamageBonus() ?? 0f;
     if (shatterBonus > 0f)
     {
         float shatterDmg = damage * shatterBonus;
         bossHealth.TakeTrueBodyDamage(shatterDmg, collider.transform.position);
     }
 }

 安全性说明：
 - 冰冻流（Frost Lv5）：TrueDamageToBoss = true + Boss 一直被减速 → Shatter 全程生效 ✓
 - 暴击流（Focus Lv5，无 Frost）：TrueDamageToBoss = true 但 IsSlowed = false → Shatter 不触发 ✓
 - 混搭 Focus+Frost+Shatter：理论上 OP，但需要 15/16 个技能槽 → 实践中不可能出现 ✓
